# Carpeta de Iconos PWA - Aura Perfume AI

Esta carpeta contiene los iconos requeridos para la Progressive Web App (PWA) de Aura. Hemos colocado iconos generados de alta resolución (SVG y PNG) para que la aplicación sea 100% instalable de inmediato.

Cuando desees colocar tus propios diseños definitivos, simplemente reemplaza los archivos manteniendo estos nombres:

- `icon-192x192.png`: Icono estándar de 192x192 px (pantalla de inicio móvil y splash screens medianas).
- `icon-512x512.png`: Icono estándar de 512x512 px (pantalla de carga de alta resolución en Android/escritorio).
- `icon-maskable-192x192.png`: Versión adaptable con zona de seguridad (safe zone) para formas circulares, cuadradas o squircle.
- `icon-maskable-512x512.png`: Versión adaptable 512x512 px para Android 8+.
- `apple-touch-icon.png`: Icono para dispositivos iOS de 180x180 px.
- `icon.svg`: Vector SVG escalable para navegadores modernos y desktop.
- `favicon-32x32.png`: Favicon para pestañas de navegador tradicionales.
